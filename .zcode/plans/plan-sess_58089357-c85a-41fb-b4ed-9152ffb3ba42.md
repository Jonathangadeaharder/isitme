## Dependency cleanup: "Required only" scope

No behavior change. Removes 2 deps + 1 feature, aligns reqwest with current 0.13 line. Tests stay green.

### Cargo.toml changes
- Remove `tokio-util` (dead: zero references in src/).
- Remove `futures-util` (replaced by reqwest native `.chunk()`).
- Remove reqwest `stream` feature (no longer needed without `bytes_stream()`).
- Remove reqwest `json` feature (we never call `Response::json()`; we use `serde_json::to_string_pretty` on our own structs).
- Bump reqwest `0.12` -> `0.13` (0.12 superseded; 0.13.4 is current stable).
- Trim tokio features: `full` -> `rt-multi-thread, macros` (only `#[tokio::main]` used).
- Bump indicatif `0.17` -> `0.18` (current stable, active today).
- Keep tabled `0.17`, owo-colors `4`, anyhow `1`, clap `4`, serde/serde_json `1`, pretty_assertions `1` as-is (per "Required only": DIY table replacement out of scope).

### src/speed.rs changes
- Remove `use futures_util::StreamExt;`.
- Rewrite `download()` body loop:
  - Before: `let mut stream = resp.bytes_stream(); while let Some(chunk) = stream.next().await { ... }`
  - After: `let mut resp = resp; while let Some(chunk) = resp.chunk().await? { ... }` (native reqwest method, not feature-gated).
- `upload()` unchanged (already uses `client.post().body(vec).send()` + `resp.bytes()`).
- Tests unchanged (pure `mbps_from_bytes_seconds` logic).
